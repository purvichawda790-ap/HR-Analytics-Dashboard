 HR Analytics Dashboard

 Overview
This project is an HR Analytics Dashboard created using Power BI. The dashboard provides insights into employee data, helping to understand workforce trends, employee attrition, demographics, and job satisfaction.

The goal of this project is to transform raw HR data into meaningful visualizations that support better decision-making.

 Tools Used
- Power BI
- Excel / CSV
- Data Cleaning
- Data Visualization

 Key Metrics
- Total Employees
- Attrition Count
- Attrition Rate
- Active Employees
- Average Age
- Gender Distribution
- Department-wise Analysis

 Dashboard Insights
- Employee attrition trends
- Department-wise employee distribution
- Gender diversity analysis
- Age group analysis
- Job satisfaction overview
